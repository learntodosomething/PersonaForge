# Privacy and Data Handling

PersonaForge processes conversation data that may include sensitive personal information.

## Minimum requirements
- Do not commit real conversation exports to the repository.
- Use synthetic data in automated tests and screenshots.
- Explain which data is stored and where.
- Prefer local processing by default where practical.
- Disclose any transfer to external model or embedding providers.
- Provide deletion of source files and derived data.
- Avoid logging raw message text or secrets.
- Require users to confirm that they have the right to process imported data.
- Do not encourage impersonation, deception, or presenting generated text as an authentic message from a real person.

This document is a development checklist, not legal advice. Review applicable privacy and data-protection requirements before public release.
